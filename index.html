🟢 日常观察

眼睛：视力正常不等于眼睛舒服

很多人的常规体检只查视力，却不会细看眼表状态、干眼倾向或屏幕使用后的不适感。这个模块帮助用户知道哪些问题值得先观察，哪些情况需要考虑进一步检查。

常规体检通常不会细查 干眼、眼表舒适度、长时间屏幕使用后的视觉疲劳
日常可以怎么观察 是否频繁酸涩、畏光、干痒、眨眼变多
什么情况建议进一步检查 如果反复出现干涩、异物感、夜间看屏困难，可考虑眼科面诊

功能结构

一页就能讲清楚产品骨架

卡通小人地图

SVG 热区点击，移动端优先，支持高亮反馈、低动效和无障碍 aria-label。

部位卡片模板

一句话重点 → 200–300 字主科普 → 可展开详情，保证信息密度和阅读节奏都友好。

关注清单生成

通过 8–10 题规则引擎问卷，生成匿名清单，不依赖 AI 诊断，不制造黑箱评分。

离职前专题页

叠加常规套餐对照表，输出可打印 A4 清单，帮助用户做体检加项决策。

分享卡片

支持生成适合微信传播的单张卡片，让“替父母整理建议”这类场景更顺手。

合规与边界

首页、卡片、结果页三处固定免责声明，明确这是健康科普工具，不是诊断产品。

技术亮点

内容可审、规则可解释、前端体验轻

Next.js + SVG 热区

响应式、移动端优先，首页可静态化，热区命中率与可访问性都更好。

Headless CMS + 医学审稿流

部位卡片、问卷规则、三色文案全部可版本化，并保留医学审校留痕。

规则引擎替代黑箱模型

关注清单采用 YAML / JSON 规则维护，医学顾问可以直接理解和复审。

匿名 Focus List

默认不收集真实姓名、联系方式，只保留生成清单所需字段，30 天自动过期。

一句话总结

把零散健康焦虑，变成一张温和、克制、可执行的关注地图

健康小人全身扫描的价值，不是让用户做更多检查，而是帮他看清：哪些值得留意，哪些不用被营销带跑。
